## What this is

One line roasting a smart fridge, and the milk it cc'd.

The entry line (67 characters):

> My smart fridge emailed me that the milk expired. It cc'd the milk.

## How the program works

- `main.ts` — Node 22, standard library only. It writes that one line
  to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
  It makes no network calls and uses no randomness or clock, so both
  grader runs write identical bytes.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
